# MPL MENA Academy — تفاصيل المشروع

ملف واحد فيه كل اللي تحتاجه عشان تشغّل المشروع على جهازك وتكمّل عليه.

---

## 1. المشروع إيه

موقع عربي (وإنجليزي) لموبايل ليجندز التنافسية في منطقة MENA. الزائر يدخل
يتعلم، يشوف الميتا، يجرّب درافت، ويتابع المباريات واللاعيبة. مفيش تسجيل
ولا حسابات.

المشروع موجود في فولدر `academy/` جوه ريبو `mlbb-esports-hub`. هو موقع
مستقل بتصميمه وبنائه، لكنه بيقرا نفس الداتا اللي الريبو بيسحبها.

| | |
|---|---|
| الريبو | `cealiomar/mlbb-esports-hub` |
| الفرع | `claude/nifty-mayer-nr0egb` |
| الفولدر | `academy/` |
| اللغة الافتراضية | العربية (`/ar/`)، والإنجليزية على `/en/` |
| العنوان المحلي | `http://localhost:3200` |

## 2. التشغيل على جهازك

المطلوب: Node.js 20 أو أحدث، و git.

```bash
git clone https://github.com/cealiomar/mlbb-esports-hub.git
cd mlbb-esports-hub
git checkout claude/nifty-mayer-nr0egb

npm ci              # مرة واحدة، في جذر الريبو

cd academy
npm run dev         # http://localhost:3200
```

`npm ci` بيتعمل في **جذر الريبو** مش جوه `academy/`. الموقع بيستخدم نفس
المكتبات المتسطبة في الجذر.

### الأوامر

كلها من جوه `academy/`:

| الأمر | بيعمل إيه |
|---|---|
| `npm run dev` | سيرفر تطوير على `localhost:3200`، بيتحدث مع كل تعديل |
| `npm run build` | بيبني الموقع ملفات ثابتة في `academy/out` |
| `npm run preview` | بيعرض النسخة المبنية على `localhost:3200` |
| `npm run sync` | بينسخ الصور من الجذر (بيتشغل لوحده قبل dev و build) |

اختبارات منطق الدرافت بتتشغل من جذر الريبو:

```bash
npx vitest run academy
```

## 5. الداتا بتيجي منين

الموقع **مش بيطلب أي داتا وهو شغال**. كل صفحة بتتبني مرة واحدة من ملفات
JSON موجودة في جذر الريبو. الداتا دي بيحدّثها GitHub Action أوتوماتيك.

| اللي بيظهر | الملف | بيتحدث بـ |
|---|---|---|
| المباريات والنتائج | `data/snapshots/matches.json` | `npm run harvest` |
| الترتيب | `data/snapshots/standings.json` | `npm run harvest` |
| التشكيلات | `data/snapshots/teams.json` | `npm run harvest` |
| صور اللاعيبة | `data/snapshots/player-photos.json` | `npm run harvest:players` |
| التصنيفات والمسارات | `data/snapshots/patch-meta.json` | `npm run harvest:meta` |
| أسماء وصور الأبطال | `data/snapshots/hero-catalog.json` | `npm run sync:hero-catalog` |
| الدروس | `content/academy.json` | تعديل يدوي |

أوامر الـ harvest بتتشغل من **جذر الريبو**. الصور متخزنة في `public/` في
الجذر، و `npm run sync` بينسخ اللي الموقع محتاجه.

لو عاوز تحدّث الداتا عندك:

```bash
# من جذر الريبو
npm run harvest
npm run harvest:players
```

## 6. محاكي الدرافت شغال إزاي

- **الترتيب**: 10 حظر بالتبادل يبدأ بالأزرق، وبعدها 10 اختيارات بترتيب
  1-2-2-2-2-1.
- **اقتراح الاختيار**: أقوى الأبطال المتاحين في الباتش للمسارات اللي الطرف
  لسه ما ملاهاش.
- **اقتراح الحظر**: أقوى الأبطال للمسارات اللي **الخصم** لسه محتاجها.
- **توزيع المسارات**: كل بطل بياخد مساره الأساسي لو فاضي، وإلا أول مسار
  تاني بيلعبه.
- **النتيجة**: متوسط تقييم الميتا لكل طرف من 100، وعدد المسارات المتغطية.

الاقتراحات مبنية على تقييم التصنيف بس. مفيش كاونترات ولا synergy بين
الأبطال لسه.

## 7. تعديلات شائعة

### إضافة فيديو لدرس

في `content/academy.json` ضيف رقم الفيديو (11 حرف) للدرس:

```json
"youtubeId": "ضع_الرقم_هنا"
```

بيشتغل مع الفيديوهات العامة والـ unlisted.

### إضافة درس

ضيف عنصر جديد في `lessons` في `content/academy.json` بنفس شكل الدروس
الموجودة: `slug`، `track`، `role`، `minutes`، والعنوان والملخص والنقاط
بالعربي والإنجليزي. الصفحة بتتبني لوحدها.

### تغيير نص في الواجهة

كل النصوص في `academy/lib/i18n.ts`، نسخة عربي ونسخة إنجليزي.

### تغيير الألوان

أول `academy/app/globals.css` فيه المتغيرات: `--gold`، `--teal`، `--bg`،
وباقي الألوان.

## 8. الرفع على Vercel

1. مشروع Vercel جديد من نفس الريبو.
2. **Root Directory** = `academy`.
3. سيب خيار "Include files outside the root directory" مفعّل، عشان البناء
   بيقرا `../data` و `../public`.
4. Framework: Next.js. أمر البناء: `npm run build`.

لسه ما اتجربش الرفع على Vercel فعليًا. اتجرب البناء والتشغيل المحلي بس.

## 9. اللي ناقص

- **39 لاعب من 70 من غير صورة**: ملهمش صفحة على Liquipedia، أو الاسم
  بيتشابه مع لاعب تاني فالصورة اترفضت. بيظهر مكانهم أول حرفين من الاسم.
- **الدروس من غير فيديوهات** لحد ما تضيف أرقام يوتيوب.
- **صنّاع المحتوى والإيفنتات**: مفيش صفحات ليهم لسه.
- **الدرافت**: من غير كاونترات، ومن غير وضع MPL (حظر على مرحلتين).
- **الثيم**: غامق بس.
- **الحقوق**: صور Liquipedia كل واحدة ليها رخصتها، ولوجو MPL علامة تجارية
  لـ Moonton. راجع ده قبل نشر عام فيه رعاة.

## 10. قاعدتين ما يتكسروش

1. **مفيش `fetch` لداتا المباريات من المتصفح أو وقت الطلب.** Liquipedia
   بتسمح بطلب واحد كل 30 ثانية، فالداتا بتتسحب مرة وتتخزن.
2. **كل الصفحات static.** بعد أي تعديل شغّل `npm run build` واتأكد إن كل
   مسار قدامه `○` أو `●`، مش `ƒ`.
